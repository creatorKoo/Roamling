# Mochi 애니메이션 — ChatGPT 이미지용 한글 프롬프트

이 파일은 설명서가 아니라 **복사해서 붙여 넣는 프롬프트 모음**이다.

## 사용 방법

1. ChatGPT에서 새 이미지 생성 대화를 연다.
2. 아래 세 이미지를 한 번에 첨부한다.
   - `01-mochi-poses-IDENTITY.png`
   - `02-fat-mochi-runtime-atlas-MOTION-REFERENCE.png`
   - `03-mochi-runtime-atlas-REJECTED.png`
3. 아래의 **1번 걷기 프롬프트만** 붙여 넣는다.
4. 결과를 확인하고 마음에 들 때만 승인한다.
5. 같은 대화에서 2번, 3번 순서로 **프롬프트 하나씩만** 붙여 넣는다.
6. 각 단계의 코드 블록에는 공통 금지사항이 이미 포함되어 있다. 문서 위쪽 설명이나 다른
   프롬프트를 함께 붙여 넣을 필요가 없다.
7. 대화를 새로 시작했다면 이미지 세 장을 다시 첨부하고 1번부터 시작한다.

한 번에 최종 atlas 전체나 여러 동작을 요청하지 않는다. 각 결과는 ChatGPT 화면 캡처가 아닌
**다운로드한 원본 PNG**로 보관한다.

## 1. 오른쪽 걷기 — 가장 먼저 붙여 넣기

```text
첨부 이미지의 역할은 다음과 같다.
- 이미지 1 `01-mochi-poses-IDENTITY.png`: Mochi 외형의 유일한 기준이다.
- 이미지 2 `02-fat-mochi-runtime-atlas-MOTION-REFERENCE.png`: 동작 종류와 흐름만 참고한다. FatMochi의 얼굴, 체형, 눈, 표정, 무늬는 복사하지 않는다.
- 이미지 3 `03-mochi-runtime-atlas-REJECTED.png`: 잘못된 결과의 참고 사례다. 이 이미지의 픽셀을 복사하거나 고쳐서 재사용하지 않는다.

Roamling macOS 데스크톱 컴패니언에 사용할 Mochi의 오른쪽 걷기 애니메이션 원화를 만들어라.
오른쪽으로 걷는 시간 순서의 프레임을 정확히 8개 만들고, 가로 한 줄에 왼쪽부터 오른쪽 순서로 배치한다.

각 프레임에서는 귀부터 꼬리와 네 발까지 고양이 전체를 새로 완성해서 그린다. 얼굴, 눈, 발, 다리, 몸통 같은 일부만 생성하거나 교체하지 않는다. 다른 프레임을 잘라 붙이거나, 부분 합성하거나, 일부 영역만 인페인팅하거나, 기존 그림 조각을 재사용하지 않는다. 잘못된 프레임이 생기면 그 프레임의 고양이 전체를 다시 그린다.

이미지 1의 Mochi를 정확히 유지한다. 크고 둥근 갈흑색 눈, 작은 분홍색 코와 입, 쫑긋한 귀, 짧지만 보이는 목, 작고 통통한 몸통, 매우 짧은 고양이 발 네 개, 줄무늬가 있는 위로 선 꼬리, 주황색·갈색·크림색 무늬의 모양과 위치, 색상, 픽셀 크기, 외곽선 굵기와 멍하고 귀여운 표정을 모든 프레임에서 동일하게 유지한다. 얼굴 크기, 눈 크기, 목 길이, 몸통 비율, 꼬리 굵기와 무늬가 프레임마다 달라지면 안 된다.

자연스러운 고양이의 4박자 보행으로 그린다. 앞발 하나만 흔드는 동작이 아니라 네 발이 모두 명확하게 움직여야 한다. 가까운 앞발과 먼 앞발은 반대 위상으로 움직이고, 두 뒷발도 서로 반대 위상으로 움직인다. 발이 바닥에 닿아 체중을 받는 프레임과, 짧게 들려 앞으로 회수되는 프레임이 모두 보여야 한다. 몸통과 머리는 안정적으로 유지하고 아주 작은 상하 움직임과 절제된 꼬리 움직임만 허용한다. 고정된 바닥선과 몸의 중심을 유지한다. 반복 재생했을 때 미끄러지거나, 공중에 뜨거나, 문워크처럼 뒤로 밀려 보이면 안 된다.

8마리 각각을 같은 너비의 영역 안에 완전히 넣고, 각 영역의 좌우에 넉넉한 순수 배경 여백을 둔다. 수염, 꼬리, 발, 털, 외곽선이 이웃 영역으로 넘어가거나 경계에 닿으면 안 된다. 이전 또는 다음 프레임의 픽셀 조각이나 떠 있는 잔여물을 남기지 않는다. 고양이에 속한 모든 픽셀은 해당 고양이 본체에 자연스럽게 연결되어야 한다. 정확히 8마리만 그리고 프레임 선, 칸 구분선, 번호, 글자는 넣지 않는다.

배경은 화면 끝까지 완전히 균일한 단색 `#00FF00` 크로마키로 만든다. 그림자, 접지 그림자, 광택, glow, 바닥, 질감, 그라데이션, 반사, 글자, 워터마크를 넣지 않는다. 고양이 내부에는 `#00FF00` 색을 사용하지 않는다. 선명하고 의도적인 픽셀아트 가장자리를 유지하며 흐림이나 회화적인 안티앨리어싱을 쓰지 않는다.

결과를 내기 전에 8개 영역 모두를 검사한다. 각 프레임에 완전한 고양이와 정확히 네 발이 있고, 외형과 무늬가 동일하며, 중심과 바닥선이 고정되고, 좌우 여백이 충분하며, 겹침·잘림·떠 있는 픽셀 조각이 없는지 확인한다.
```

## 6. 축하 점프와 착지 — 마지막으로 붙여 넣기

```text
현재 대화에서 승인한 Mochi의 외형을 그대로 유지하면서 Roamling용 작은 축하 점프와 착지 애니메이션을 만들어라. 정면을 향한 시간 순서의 프레임을 정확히 6개 만들고 가로 한 줄에 배치한다.

각 프레임마다 귀부터 꼬리와 네 발까지 고양이 전체를 새로 완성해서 그린다. 일부 신체만 수정하거나 교체하지 않는다. 부분 생성, 부분 합성, 잘라 붙이기, 일부 영역만 인페인팅, 다른 프레임 조각 재사용을 금지한다. 실패한 프레임은 전체 고양이를 다시 그린다.

Mochi의 큰 갈흑색 눈, 작은 코와 입, 귀, 짧은 목, 통통한 몸통, 매우 짧은 네 발, 줄무늬 꼬리, 주황색·갈색·크림색 무늬, 색상과 외곽선을 일관되게 유지한다.

동작은 정확한 기본 idle → 작게 웅크림 → 네 발을 짧게 접으며 낮게 상승 → 작은 공중 정점 → 부드러운 착지와 작은 squash → 정확한 idle 복귀 순서다. 수평 중심을 고정하고 높이 뛰거나 옆으로 이동하지 않는다. 팔다리를 길게 만들지 않는다. 별, 꽃가루, 글자, 별도 효과를 추가하지 않는다. 첫 자세와 마지막 자세가 승인된 idle과 정확히 이어져야 한다.

각 고양이를 동일한 너비의 영역 안에 완전히 넣고 좌우에 넉넉한 여백을 둔다. 이웃 프레임 침범, 경계 접촉, 잘림, 떠 있는 픽셀이나 잔여물을 금지한다. 정확히 6마리만 그리고 프레임 선, 번호, 글자는 넣지 않는다.

배경은 완전히 균일한 단색 `#00FF00`이다. 그림자, 바닥, 질감, 그라데이션, 반사, glow, 글자와 워터마크가 없어야 한다. 고양이 내부에는 `#00FF00`을 사용하지 않는다. 선명한 픽셀아트 가장자리를 유지한다.
```

## 결과가 잘못됐을 때 사용하는 수정 프롬프트

부분 수정으로 해결하지 말고 아래처럼 해당 strip 전체를 다시 요청한다.

```text
이 결과는 승인하지 않는다. [문제가 있는 부분을 한 문장으로 설명] 문제가 있다.
특정 눈, 발, 얼굴 또는 픽셀 조각만 고치거나 붙이지 말고, 직전 요청의 외형·동작·배경·여백 규칙을 모두 유지하면서 이 애니메이션 strip 전체를 처음부터 다시 그려라. 각 프레임의 고양이는 부분 합성이 아닌 완성된 전체 그림이어야 한다.
```
